# Product

## Register

product

## Platform

web

## Users

HJAR Sysinfo digunakan oleh staf operasional, kontributor data, moderator, dan administrator yang memeriksa, membandingkan, memperbarui, serta menjaga kualitas data properti sepanjang hari. Mereka bekerja terutama pada desktop di lingkungan kantor yang terang, dengan kebutuhan mobile web untuk akses lengkap saat berpindah tempat.

## Product Purpose

Produk ini menyediakan satu meja kerja digital untuk mengelola siklus data pembanding properti: autentikasi, pencarian dan penyaringan, input dan validasi, pemetaan, pemeriksaan duplikasi, moderasi, import/export, administrasi referensi, serta audit sistem. Keberhasilan berarti pengguna dapat menyelesaikan tugas berisiko dan berdensitas tinggi dengan cepat, akurat, dapat ditelusuri, dan tanpa status sistem yang ambigu.

## Brand Personality

Presisi, tenang, dan tepercaya. Suara produk ringkas, langsung, serta membantu pengguna memahami keadaan dan langkah berikutnya tanpa bahasa dekoratif atau teknis yang tidak perlu.

## Anti-references

Produk tidak boleh terasa seperti landing page SaaS, dashboard gelap bergaya terminal, atau kumpulan kartu dekoratif. Hindari glassmorphism, gradient, shadow berat, card bersarang, radius berlebihan, animasi teatrikal, kontrol eksperimental, warna semantik sebagai dekorasi, dan informasi penting yang hanya dapat dipahami dari warna.

## Design Principles

1. Tugas utama selalu lebih jelas daripada dekorasi dan secondary action.
2. Data padat harus cepat dipindai tanpa menyembunyikan konteks, status, atau aksi kritis.
3. Setiap permintaan data memiliki state loading, empty, error, stale, forbidden, offline, dan retry yang eksplisit.
4. URL, permission, dan server state mempunyai pemilik yang jelas sehingga perilaku dapat diprediksi dan dibagikan.
5. Familiaritas, konsistensi, dan keselamatan operasi lebih penting daripada kejutan visual.

## Accessibility & Inclusion

Target utama adalah WCAG 2.2 AA. Seluruh flow kritis harus dapat digunakan dengan keyboard dan screen reader, tetap terbaca pada zoom 200%, tidak mengandalkan warna saja, menghormati reduced motion, memiliki target sentuh minimum 44px pada coarse pointer, serta menyediakan alternatif tekstual untuk chart dan alternatif non-peta untuk data lokasi.
